# Danny's Diner SQL Case Study

This is a SQL practice project based on Danny Ma's 8 Week SQL Challenge (Case Study 1).

I used SQL to analyze customer orders, spending habits and popular menu items at Danny's Diner.

## Why I Did This Project

I did this project to test my SQL skills and show what I can do with SQL, especially JOINs, GROUP BY, CASE WHEN and window functions.

## Dataset

The dataset has three tables:
- `sales` - customer orders
- `menu` - menu items and prices
- `members` - customer membership information
